# Sprint completion

- When a sprint is fully implemented and its relevant checks pass, close its corresponding GitHub issues with the completed reason as part of finishing the work.
- Verify the issue states on GitHub and keep the local sprint JSON files and overview consistent with them. Updating local status alone does not complete a sprint.
- Keep unfinished or partially implemented issues open and report any blocker that prevents closure.
- Include the completed sprint and closed issue numbers in the final status update.

# Improvement suggestions

- In the final update for implementation work, suggest one concrete new feature that would help Quikz. Keep it separate from implemented work; do not expand the scope automatically.
