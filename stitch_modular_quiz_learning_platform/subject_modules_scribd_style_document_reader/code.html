4.2 Dijkstra's Greedy Relaxation Loop

Let $G = (V, E)$ be a directed weighted graph where each weight $w(u, v) \ge 0$. We maintain two disjoint sets of vertices: $S$, the set of vertices whose shortest distances from the source vertex $s$ have already been finalized, and $V \setminus S$, the remaining exploration fringe.

Extraction order is governed by the heap extract-min primitive. Notice how negative edge weights violate the subpath greedy invariant.

data_object Formal Algorithm Specification 

function Dijkstra(Graph, source):
    create vertex set Q
    for each vertex v in Graph.Vertices:
        dist[v] ← INFINITY
        prev[v] ← UNDEFINED
        add v to Q
    dist[source] ← 0
    
    while Q is not empty:
        u ← vertex in Q with min dist[u]
        remove u from Q
        
        for each neighbor v of u still in Q:
            alt ← dist[u] + Graph.Edges(u, v)
            if alt < dist[v]:
                dist[v] ← alt
                prev[v] ← u
                
    return dist[], prev[]
