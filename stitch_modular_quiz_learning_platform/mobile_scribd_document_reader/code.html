4.2 Dijkstra's Greedy Relaxation Loop

The core invariant of Dijkstra's algorithm states that whenever a vertex u is extracted from the indexed priority queue Q, its tentative distance d[u] is definitively equal to the true shortest path distance δ(s, u).

Triangle Inequality Criterion functions
d[v] ≤ d[u] + w(u, v)

If d[v] > d[u] + w(u, v), edge (u, v) is relaxed, strictly decreasing tentative distance toward target node v.

RELAXATION LOGIC (PSEUDOCODE) O(log V) 
def relax_edge(u, v, w):
    if dist[v] > dist[u] + w(u, v):
        dist[v] = dist[u] + w(u, v)
        parent[v] = u
        pq.decrease_key(v, dist[v])
        # Yield state for visual trace
        return True
    return False
